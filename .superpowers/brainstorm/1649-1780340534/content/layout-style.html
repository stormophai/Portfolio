A — Horizontal List

Stacked rows. Each project = full-width card with thumbnail, title, short description, tags, live link. Clean, readable, scannable. Serious portfolio feel.

B — 3-Column Grid

Equal-size cards in a row. Image on top, title + tags below. Hover reveals a live-link button. Compact, visual, modern. Like the existing Portfolio section but for real clients.

C — Spotlight + 2 Small

One featured project dominates left (bigger card, more detail), two smaller cards stack right. Creates visual hierarchy — great if one project is the star. Asymmetric, editorial feel.
